# KayG desktop app

Tauri 2 + React frontend for KayG, an independent desktop client compatible with the Grok Build CLI.

From this directory:

```bash
pnpm install
pnpm tauri dev
```

From repo root: `pnpm install --dir apps/desktop && pnpm dev`.

See the [root README](../../README.md) for system prerequisites (WebKit/GTK on Linux) and architecture docs.
