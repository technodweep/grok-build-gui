# KayG — Grok Build desktop GUI

Tauri 2 + React frontend for KayG, an independent, open-source Grok Build GUI
and cross-platform desktop client from Technodweep.

From this directory:

```bash
pnpm install
pnpm tauri dev
```

From repo root: `pnpm install --dir apps/desktop && pnpm dev`.

See the [root README](../../README.md) for system prerequisites (WebKit/GTK on Linux) and architecture docs.
